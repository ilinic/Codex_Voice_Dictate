# Codex Voice Dictate

Voice dictation for Codex on Windows. The app lives in the system tray, recognizes speech, and inserts prompts into the Codex composer—even when you're using Codex with an API key.

**[Download the latest Windows `.exe`](https://github.com/ilinic/Codex_Voice_Dictate/releases/latest/download/CodexVoiceDictate.exe)** · [All releases](https://github.com/ilinic/Codex_Voice_Dictate/releases)

Run the file, then right-click the tray icon → **Settings** to enter your OpenAI API key and choose languages. Press **F8** to dictate or **F9** to dictate and send.
