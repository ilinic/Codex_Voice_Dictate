# Codex Voice Dictate

Voice dictation into Windows text fields, including Codex and IntelliJ IDEA. The app lives in the system tray, recognizes speech, and inserts prompts using your OpenAI API key.

**[Download the latest Windows `.exe`](https://github.com/ilinic/Codex_Voice_Dictate/releases/latest/download/CodexVoiceDictate.exe)** · [All releases](https://github.com/ilinic/Codex_Voice_Dictate/releases)

Run it, then right-click the tray icon → **Settings** to configure your API key and languages. Focus a text field and press **Ctrl+Alt+B** to bind it; use **F8** to dictate or **F9** to stop and send when verification is available.
